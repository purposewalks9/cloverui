Clover UI is a collection of animated React components built with Tailwind CSS and Motion. Each one installs as source code into your project, so it is yours to read, change and ship.

## Why Clover UI

Small details decide whether an interface feels considered or rushed: a button that presses back, a card that switches songs, a hand that shows people where to click. Clover UI collects those details as components you can drop in and tune, instead of rebuilding them for every project.

- **You own the code.** Components install through the shadcn CLI as plain files, not a package, so there is nothing to upgrade or work around.
- **Built on what you already use.** React, Tailwind CSS v4, Motion and the shadcn conventions you know, like `cn()` and `cva`.
- **Made to be tuned.** Components come with a live playground in the docs. Change the props, then copy the code.
- **Careful by default.** Components are checked in light and dark mode, work with the keyboard, and calm down when someone prefers reduced motion.

## How it works

1. [Add the Clover UI registry](/docs/installation) to your `components.json` once.
2. Install any component with one command, or let your AI editor do it through [MCP](/docs/mcp).
3. The component lands in your `components` folder. Edit it like the rest of your code.
