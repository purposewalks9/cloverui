## Usage

```tsx
import { ThinkingState } from "@/components/thinking-state";

<ThinkingState />
```

A small pixel animation right next to a word, with no box around it, for showing what an agent or app is doing. The lit pixels draw each state's shape over a light gray grid that follows your theme, and a soft shimmer sweeps across the text, which uses your theme's text color. Each state has its own animation and color:

- `thinking`: a green trail of dots chasing in a loop.
- `analyzing`: light blue arcs scanning around a circle.
- `debugging`: a blue diagonal wave sweeping across.
- `searching`: a violet dot looping around with a trail.
- `building`: orange pixels stacking up row by row.
- `pondering`: pink ripples spreading out from the center.

```tsx
<ThinkingState state="debugging" />
```

The text defaults to the state's name. Pass children to change it, and `color` to change the pixels:

```tsx
<ThinkingState state="thinking" color="#a855f7">
  Galavanting
</ThinkingState>
```

Set `color="loop"` to cycle smoothly through all the state colors. Set `pixel="circle"` for round dots arranged in a circle instead of a square grid, and `grid={false}` to hide the gray grid so only the lit pixels show on a transparent background.

Set the size with a text class in `className`. The pixels scale with the text. Set `shimmer={false}` to turn off the shimmer, and `speed` to make the animation faster or slower. When reduced motion is on, the pixels hold still and the text doesn't shimmer.

It has `role="status"`, so screen readers announce the text when it changes.
