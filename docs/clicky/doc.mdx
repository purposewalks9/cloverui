## Usage

```tsx
import { Clicky } from "@/components/clicky";

<Clicky>
  <span>Click here</span>
</Clicky>
```

When the element scrolls into view, the hand pops in on top of it and presses it with a soft glow, then keeps pressing every `interval` seconds. It is only an effect by default. Pass `autoClick` if the press should also click the element. When reduced motion is on, the hand appears without pressing.
