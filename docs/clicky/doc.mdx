## Usage

```tsx
import { Clicky } from "@/components/clicky";

<Clicky>
  <button>Get started</button>
</Clicky>
```

The hand waits until the element scrolls into view, glides in along a soft arc with a glowing trail, presses it and then keeps hovering over it. It is only an effect by default. Pass `autoClick` if the press should also click the element. When reduced motion is on, the hand appears in place without gliding or pressing.
