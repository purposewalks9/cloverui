## Examples

### Sequential pattern

`pattern="sequential"` reveals blocks in row order instead of scattered.

<DemoCanvas>
  <DemoPreview><SequentialDemo /></DemoPreview>
  <DemoCode>
```tsx
    <GridReveal
      rows={8}
      cols={8}
      color="#8B5CF6"
      pattern="sequential"
      blockDuration={0.22}
      stagger={0.012}
    >
      <YourContent />
    </GridReveal>
```
  </DemoCode>
</DemoCanvas>

### Denser grid

More rows and columns make for a finer-grained reveal.

<DemoCanvas>
  <DemoPreview><DenseDemo /></DemoPreview>
  <DemoCode>
```tsx
    <GridReveal rows={12} cols={12} color="#60A5FA" pattern="random">
      <YourContent />
    </GridReveal>
```
  </DemoCode>
</DemoCanvas>

### Slower reveal

Increase `blockDuration` and `stagger` for a more deliberate animation.

<DemoCanvas>
  <DemoPreview><SlowDemo /></DemoPreview>

## Usage

```tsx
import { GridReveal } from "@/components/grid-reveal";

<GridReveal rows={8} cols={8} color="#E1E900">
  <YourContent />
</GridReveal>
```
