## Usage

A real jigsaw puzzle that assembles (or breaks apart) and can be filled with a color, an image, or any element.

```tsx
import { PuzzleBg } from "@/components/puzzle-bg";

// color
<PuzzleBg color="#E1E900" className="h-64 w-full" />

// image
<PuzzleBg image="/photo.jpg" className="aspect-video w-full" />

// any div or element, cut into pieces
<PuzzleBg rows={3} cols={4} className="aspect-video w-full">
  <div className="grid h-full w-full place-items-center bg-neutral-900 text-white">
    Hello
  </div>
</PuzzleBg>
```

Fill order is children, then `image`, then `color`. To use it as a page or card background, position it behind your content (`absolute inset-0`).

Children are rendered once per piece, so keep them light (images, cards, text). For anything heavy, pass an `image` instead.
