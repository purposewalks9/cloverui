## Usage

```tsx
import { SpookyTv } from "@/components/spooky-tv";

<SpookyTv state="thinking" palette="pumpkin" />
```

Spooky TV is a retro television drawn in fine lines with a glowing jack-o'-lantern on its screen. The candle inside flickers, the pumpkin blinks now and then, and its eyes follow the pointer.

It's made to show what an AI agent is doing. Pass the agent's status as `state` and the face changes smoothly to match:

- `idle`: a classic toothy grin.
- `thinking`: eyes look up, the mouth goes small and thought dots float up beside it.
- `working`: focused eyes scan left and right while a light sweeps down the screen.
- `done`: happy ^ ^ eyes and a big grin.
- `error`: angry eyes and a frown, and the face glows the alert color and shakes.

```tsx
"use client";

import { SpookyTv, type SpookyTvState } from "@/components/spooky-tv";

export function AgentStatus({ status }: { status: SpookyTvState }) {
  return <SpookyTv state={status} className="max-w-xs" />;
}
```

The TV body uses your theme's colors, so it works in light and dark mode. The screen, pumpkin, face and knobs come from the `palette`. The palettes are exported as `SPOOKY_TV_PALETTES`, so you can read or extend them.

It only animates while it is on screen and the tab is open. With `animate` off, or for people who prefer reduced motion, the face still changes with `state` but jumps straight to it, with no flicker, blinking or shaking.

The drawing style is inspired by [Hairline](https://hairline.lucasmarkes.com) by Lucas Marques: rounded solids, a bright outline outside and a dim crease inside.
