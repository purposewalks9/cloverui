## Usage

```tsx
import { TokenFall } from "@/components/token-fall";

<div className="relative h-72 w-full overflow-hidden rounded-2xl">
  <TokenFall count={34} minSize={12} maxSize={25} />
</div>
```

It fills its parent, so give the parent a position and a height. Move your cursor near the tokens to push them away.
