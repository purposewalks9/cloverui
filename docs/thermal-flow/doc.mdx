## Usage

A smooth, animated thermal-gradient background rendered on the GPU. No dependencies.

```tsx
import { ThermalFlow } from "@/components/thermal-flow";

<div className="relative h-80 w-full overflow-hidden rounded-2xl">
  <ThermalFlow theme="thermal" />
  <div className="relative p-6 text-white">Your content</div>
</div>
```

It is `absolute inset-0`, so put it in a `relative` parent and layer your content above it.

Themes: `thermal`, `aurora`, `sunset`, `ocean`, `ember`, `candy`, `mono`. For your own palette pass 2 to 8 colors from dark to bright:

```tsx
<ThermalFlow colors={["#05060f", "#1d4ed8", "#38bdf8", "#fde047", "#f97316"]} />
```

The last color is the hot ridge line right before the palette wraps back to the first, so the edge shows where the palette snaps around.

It pauses when off screen or in a hidden tab, holds a still frame with `prefers-reduced-motion`, and falls back to a plain CSS gradient if WebGL is unavailable. Lower `resolution` to go lighter on the GPU.
