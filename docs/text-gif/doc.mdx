## Usage

```tsx
import { TextGif } from "@/components/text-gif";

<TextGif src="/seal.gif">
  CLOVER UI
</TextGif>
```

## How it works

`TextGif` uses the text itself as a visual mask. The GIF is rendered as the background of the text and clipped to the letter shapes using `background-clip: text`.

This allows the animation to continuously play inside the text while keeping the surrounding area transparent.

The component accepts normal text styling classes, so font size, weight, tracking, alignment, and other typography properties can be controlled with `className`.
