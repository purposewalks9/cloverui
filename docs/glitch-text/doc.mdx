## Usage

```tsx
import { GlitchText } from "@/components/glitch-text";

<GlitchText className="text-4xl font-bold">SIGNAL LOST</GlitchText>
```

Text that looks like a broken screen. Every so often it glitches: faded slices of the text tear sideways, the whole line shakes left and right, the letters jitter and skew, and a few characters flicker into random symbols before snapping back.

By default it glitches on its own every few seconds. Set `trigger="hover"` to glitch only while the pointer is over it, or `trigger="always"` to keep it glitching. It uses the text's own color, so it works in light and dark mode. Pass `colors` for a colored split. Screen readers always hear the real text.

```tsx
<GlitchText trigger="hover" colors={["#ef4444", "#22d3ee"]}>
  HOVER ME
</GlitchText>
```

With reduced motion on, the text stays still and never glitches.
