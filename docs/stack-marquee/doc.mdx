## Usage

```tsx
import { SiClaude, SiGithub, SiOpenai } from "@icons-pack/react-simple-icons";
import { StackMarquee } from "@/components/stack-marquee";

const logos = [
  { name: "Claude", icon: <SiClaude color="default" /> },
  { name: "OpenAI", icon: <SiOpenai /> },
  { name: "GitHub", icon: <SiGithub /> },
  { name: "Your agent", src: "/icons/agent.svg" },
];

<StackMarquee logos={logos} />
```

A compact strip of the models, agents, and tools your product works with. Logos loop continuously through the center, then fade out at both ends. The strip has no card or background, so it blends into light or dark surfaces.

Pass your own image URLs or React icons through `logos`. Every item needs a `name` and either `src` or `icon`. The demo shows Claude, OpenAI, OpenClaw, Grok, GitHub, Vercel, Cursor, Gemini, Mistral AI, Hugging Face, Model Context Protocol, and LangChain with their official marks. They are examples, not endorsements, so check each brand's guidelines before shipping its logo.

`speed` sets pixels per second, so the pace stays consistent when the number of logos changes. `direction` reverses the loop. The strip repeats enough copies to cover its container, even with a short list.

Hovering pauses the loop by default. Keyboard focus always pauses it, and `paused` lets your own control stop it. Reduced motion shows a still strip. It also pauses off screen and in hidden tabs. Screen readers receive each logo name once, without the repeated visual copies.
