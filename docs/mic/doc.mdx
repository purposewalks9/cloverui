## Usage

```tsx
import { Mic } from "@/components/mic";

<Mic onStateChange={(state) => console.log(state)} />
```

The microphone starts muted, with a slash across it. Click it to ask for access and start listening: the slash slides away and the bar inside the microphone follows your real input level. Click again to mute and release the microphone. If access is blocked, the icon dims, its label explains why, and the next click asks again.
