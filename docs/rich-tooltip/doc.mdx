## Usage

```tsx
import { RichTooltip } from "@/components/rich-tooltip";

<RichTooltip label="Change of airport" route={["IST", "SAW"]} badge="1d 2h">
  <button>Details</button>
</RichTooltip>
```

Wrap any element. The tooltip springs in when the pointer rests on it or it gets keyboard focus, and leaves when the pointer moves away, focus moves on, or Escape is pressed. On touch screens, tap to show it and tap anywhere else to hide it.

`label` is the main text. `route` adds small chips joined by arrows, and `badge` adds one highlighted chip at the end, such as a time or a count. All three are optional apart from `label`.

The `solid` variant uses the theme's text color, so it is dark in light mode and light in dark mode. `surface` matches the page and relies on its shadow. Pass `color` and `textColor` for any other color. The chips and badge follow it automatically.

Set `open` to keep it visible, for example in a static mockup. Text size and spacing scale with `contentClassName`, for example `contentClassName="text-base"`.
