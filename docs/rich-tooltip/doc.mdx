## Usage

```tsx
import { RichTooltip } from "@/components/rich-tooltip";

<RichTooltip label="Copy link">
  <button>Copy</button>
</RichTooltip>
```

Wrap any element. The tooltip fades in right away when the pointer rests on it or it gets keyboard focus, and leaves when the pointer moves away, focus moves on, or Escape is pressed. On touch screens, tap to show it and tap anywhere else to hide it. It takes about a tenth of a second to appear, with no bounce.

The `solid` variant uses the theme's text color, so it is dark in light mode and light in dark mode. `surface` matches the page, with a thin border. Set `delay` if you want it to wait a little before showing.

Set `open` to keep it visible, for example in a static mockup. Change the text size with `contentClassName`, for example `contentClassName="text-sm"`.
