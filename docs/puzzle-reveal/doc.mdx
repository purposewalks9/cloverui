## Usage

```tsx
import { PuzzleReveal } from "@/components/puzzle-reveal";

<PuzzleReveal rows={4} cols={5} pattern="random">
  <img src="/image.jpg" alt="Your content" />
</PuzzleReveal>
```

`PuzzleReveal` works with any React content underneath it — images, cards, text, video, or custom layouts.
