## Examples

### Custom color

Each ring is derived from `color`, mixed toward white the further out it sits — pass any color and the whole loader recolors itself.

<DemoCanvas>
  <DemoPreview><AccentDemo /></DemoPreview>
  <DemoCode>
```tsx
    <PulseLoader color="#E1E900" size={160} />
```
  </DemoCode>
</DemoCanvas>
