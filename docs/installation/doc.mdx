Clover UI components install with the shadcn CLI. You need a React project with Tailwind CSS v4.

## Set up shadcn

Skip this if your project already has a `components.json`.

```bash
npx shadcn@latest init
```

## Add the registry

Add Clover UI to the `registries` field in `components.json`:

```json
{
  "registries": {
    "@clover-ui": "https://cloverui.xyz/r/{name}.json"
  }
}
```

For now, this step is required. Without it, the CLI stops with `Unknown registry "@clover-ui"`. Clover UI is waiting to be listed in the [shadcn registry directory](https://ui.shadcn.com/docs/directory). Once it's listed, the CLI will find `@clover-ui` on its own and you can skip this step.

## Add a component

Or install just the ones you need, by name:

<CodeBlockCommand item="clicky" />

The CLI copies the component into your project and installs what it needs, such as `motion`. Then import it like any other file:

```tsx
import { Clicky } from "@/components/clicky";
```

## Without the registry

Every component is also published as a plain URL, so you can install without touching `components.json`:

```bash
npx shadcn@latest add https://cloverui.xyz/r/clicky.json
npx shadcn@latest add https://cloverui.xyz/r/all.json
```

Or open any component page, pick the **Manual** tab under Installation, and copy the source yourself.
