Clover UI components install with the shadcn CLI. You need a React project with Tailwind CSS v4.

## Set up shadcn

Skip this if your project already has a `components.json`.

```bash
npx shadcn@latest init
```

## Add a component

Or install just the ones you need, by name:

<CodeBlockCommand item="clicky" />

Clover UI is listed in the [shadcn registry directory](https://ui.shadcn.com/docs/directory), so the CLI finds `@clover-ui` on its own. No `components.json` changes are needed.

The CLI copies the component into your project and installs its dependencies, such as `motion`. Then import it like any other file:

```tsx
import { Clicky } from "@/components/clicky";
```

## Install from a URL

Every component is also published as a plain URL, which works with any version of the shadcn CLI:

```bash
npx shadcn@latest add https://cloverui.xyz/r/clicky.json
npx shadcn@latest add https://cloverui.xyz/r/all.json
```

You can also open any component page, choose the **Manual** tab under Installation, and copy the source yourself.
