Clover UI components install directly from the Clover UI registry with the shadcn CLI. You need a React project with Tailwind CSS v4.

## Set up shadcn

Skip this if your project already has a `components.json`.

```bash
npx shadcn@latest init
```

## Add a component

Install just the components you need:

<CodeBlockCommand item="clicky" />

The CLI copies the component into your project and installs its dependencies, such as `motion`. Then import it like any other file:

```tsx
import { Clicky } from "@/components/clicky";
```

## Optional: registry namespace

If you prefer shorter `@clover-ui/name` commands, add the registry to `components.json`:

```json
{
  "registries": {
    "@clover-ui": "https://cloverui.xyz/r/{name}.json"
  }
}
```

Then run `npx shadcn@latest add @clover-ui/clicky`. This configuration is optional when installing with the full URL. Once Clover UI is included in the published shadcn registry directory, the namespace may work without manual configuration.

You can also open any component page, choose the **Manual** tab under Installation, and copy the source yourself.
