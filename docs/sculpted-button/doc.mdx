## Usage

```tsx
import { SculptedButton } from "@/components/sculpted-button";

<SculptedButton onClick={() => console.log("Run")}>Run</SculptedButton>
```

A white sculpted button with a thick rounded rim, a softly recessed face and a visible gray base. Pressing lowers the whole top into the base, using the same lift depth as Theme Toggle. The press is immediate; release gently returns the top to its resting height. It stays white in both light and dark themes.

Use the circle shape for a round icon button. Give icon-only buttons an accessible name:

```tsx
import { Play } from "lucide-react";

<SculptedButton shape="circle" aria-label="Run">
  <Play aria-hidden fill="currentColor" />
</SculptedButton>
```

Mouse, touch, Enter and Space activate the native button. It defaults to `type="button"`; pass `type="submit"` to submit a form. Disabled buttons cannot activate. Reduced motion removes the return transition while preserving immediate pressed feedback. Standard button attributes, event handlers, `ref`, `className` and `style` reach the root button.

The component uses Tailwind CSS v4, the usual shadcn `cn` helper, and your host's `ring` and `background` tokens for keyboard focus. Its white material and dark label are intentional artwork colors. Circle buttons are for icons; use the pill shape for text labels.
