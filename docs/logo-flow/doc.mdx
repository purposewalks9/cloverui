## Usage

```tsx
import { LogoFlow } from "@/components/logo-flow";

const logos = [
  { name: "Your app", src: "/icons/app.svg" },
  { name: "Your plugin", src: "/icons/plugin.svg" },
  { name: "Your AI tool", src: "/icons/ai.svg" },
];

<LogoFlow logos={logos} />
```

A compact strip of software, plugin, and integration icons. Logos loop continuously through the center, then soften and fade at both ends. The strip has no card or background, so it blends into light or dark surfaces.

Pass your own image URLs or React icons through `logos`. Every item needs a `name` and either `src` or `icon`. The demo uses brand icons; those brands are examples, not endorsements.

`speed` sets pixels per second, so the pace stays consistent when the number of logos changes. `direction` reverses the loop. The strip repeats enough copies to cover its container, even with a short list.

Hovering pauses the loop by default. Keyboard focus always pauses it, and `paused` lets your own control stop it. Reduced motion shows a still strip. It also pauses off screen and in hidden tabs. Screen readers receive each logo name once, without the repeated visual copies.
