## Usage

```tsx
import { Gem } from "@/components/gem";

<Gem size={180} grain={0.02} />
<Gem color="#14d977" material="solid" />
```

A real 3D cut gem using the same WebGL rendering and drag rotation approach as Grain Cube. Its smooth material stays fixed: there is no animated surface, flowing color, inner shimmer, or outer glow. The canvas has no background.

Drag to turn the object on two axes. It has gentle inertia and settles back to its resting pitch like Grain Cube. You can also focus it and use the arrow keys. Disable `interactive` for a decorative gem.

The default is a light, translucent glass body. Use `material="solid"` for a smooth opaque body, and `color` for its tint. `grain` defaults to `0.02`; set it to `0` for an entirely smooth surface.

The object stays still by default. Set `animate` to rotate the whole gem automatically, and `speed` to adjust the rotation. The material never animates independently. Automatic rotation pauses off screen, in a hidden tab, and when reduced motion is enabled.

`size` sets the canvas height in pixels. Its width is 95% of that height, leaving room to rotate without clipping. The `glow` prop controls polished reflections for compatibility with earlier versions; it does not create an outer glow.
