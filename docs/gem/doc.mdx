## Usage

```tsx
import { Gem } from "@/components/gem";

<Gem color="#ff2d55" size={160} />
```

A cut crystal rendered in real 3D on the GPU. It is just the gem, with no card or background, so it sits on anything like an icon or an image. Light catches its many facets and the edges glow. Inside, the light breaks into small shards and glints around a bright core near the bottom tip, and a soft glow spills around it.

Pass any hex color to `color` and everything follows it. Some to try: ruby `#ff2d55`, sapphire `#2f6bff`, emerald `#14d977`, amethyst `#a855f7`, topaz `#ff9f1c` and diamond `#dff4ff`.

`size` is the gem's height in pixels, and it is about half as wide. The glow spills a little past that box without taking extra space in your layout.

The gem stays still. Only the light inside shifts slowly, and it pauses when the gem is off screen. Set `animate={false}` to freeze it. It is also frozen when reduced motion is on.
