## Usage

```tsx
import { Gem } from "@/components/gem";

<Gem color="#c026ff" size={160} />
```

A polished cut crystal rendered in real 3D on the GPU. It has a clean glass body, sharp facets, and soft studio reflections. Refraction and tinted internal reflections give it depth, with no outer glow, cloudy fill, or shard texture. The surrounding canvas is transparent, so the gem sits directly on your page.

Pass any hex color to `color`. Try ruby `#ff2d55`, sapphire `#2f6bff`, emerald `#14d977`, amethyst `#c026ff`, topaz `#ff9f1c`, or diamond `#dff4ff`.

`size` is the gem's height in pixels, and its layout box is 42% as wide. The transparent canvas extends past that box to leave room for the angled facets.

The gem stays still while the reflected studio light shifts slowly. Set `animate={false}` to freeze it. Animation pauses off screen and when reduced motion is enabled.
