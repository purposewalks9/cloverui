## Usage

```tsx
import { CursorTag } from "@/components/cursor-tag";

<div className="relative">
  <h1>Introducing</h1>
  <CursorTag label="Admin" side="left" className="absolute -top-8 left-4" />
  <CursorTag label="Content Reviewer" color="#7c3aed" className="absolute -bottom-10 right-0" />
</div>
```

Place each tag with `absolute` positioning. Use `side="left"` when the label should sit on the left and the cursor should point to the right.
