## Examples

### Custom active color

`activeColor` defaults to green, but takes any color — whichever item is currently active, plus the tracking dot, switch to it as the list cycles.

<DemoCanvas>
  <DemoPreview><BlueDemo /></DemoPreview>
  <DemoCode>
```tsx
    <CycleList
      items={["Slower reviews", "Scope creep", "Missed deadlines"]}
      activeColor="#60A5FA"
    />
```
  </DemoCode>
</DemoCanvas>
