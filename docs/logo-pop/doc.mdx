## Usage

```tsx
import { LogoPop } from "@/components/logo-pop";

<LogoPop
  logos={[
    { name: "Acme", src: "/logos/acme.svg", ratio: 4 },
    { name: "Globex", src: "/logos/globex.svg", ratio: 3 },
  ]}
/>
```

Logo Pop is a "trusted by" logo grid with some life in it. When it scrolls into view, the logos pop in one by one in a random order. Each one lands a little too big and tilted, then settles straight into its own spot. Nothing overlaps. After that the logos stay, and every so often one gives a small bounce.

The grid has 4 columns, and 2 on small screens. Change it with `className`, for example `className="sm:grid-cols-6"`. Use a text size class to make every logo bigger or smaller.

The logos are drawn in the current text color, so they match light and dark mode. They use `text-foreground/80` by default. Change the color with a class such as `text-muted-foreground`. Any single-color SVG or PNG works as a logo, because only its shape is used.

`ratio` is the logo's width divided by its height. It balances the sizes so that wide logos and tall logos look about the same size. Each logo's `name` is read by screen readers.

With reduced motion on, the logos show right away without moving.

### Logos

The default logos are Vercel, OpenAI, Linear, Notion, Cursor, Framer, Discord, Google, Shopify, Netflix, Ramp, Descript, Duolingo, Phantom, OpenSea and Tesla, taken from the open source [Spell UI](https://github.com/xxtomm/spell-ui) (MIT license). They load from `cloverui.vercel.app` and are exported as `logoPopLogos`. Each logo is a trademark of its company, so use them only as placeholders and swap in the companies you actually work with.
