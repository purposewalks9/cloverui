## Usage

```tsx
import { ThemeToggle } from "@/components/theme-toggle";

<ThemeToggle />
```

A round, glossy black button. It shows a sun in light mode and a moon in dark mode. Tap it and the theme flips: the icon spins out and the other one spins in.

It feels soft to touch. Pressing squeezes it a little and it springs back with a small bounce when you let go, and each tap sends a ripple out from where you pressed. With a mouse, a spotlight follows the cursor and the rim lights up on the side nearest the pointer.

It also shows the right icon on the very first frame, before the page's JavaScript loads, as long as your theme uses the `dark` class (the next-themes default for shadcn).

It switches your site's theme through [next-themes](https://github.com/pacocoursey/next-themes), the same setup as the shadcn dark mode guide. Wrap your app in its `ThemeProvider` with `attribute="class"` and the toggle works with no props.

Not using next-themes? Pass `theme` and `onThemeChange` and handle the theme yourself:

```tsx
const [theme, setTheme] = useState<"light" | "dark">("light");

<ThemeToggle theme={theme} onThemeChange={setTheme} />
```

Screen readers hear "Switch to dark mode" or "Switch to light mode", and it works with Tab, Enter and Space. With reduced motion on, the icons swap with a fade and there is no squeeze or ripple.
