A number that counts up to its value with a small trailing icon, styled like a stat callout.

<GaugeTextPlayground />

## Installation

<InstallationTabs item="gauge-text">

## Usage

```tsx
import { GaugeText } from "@/components/gauge-text";

<GaugeText value={89} suffix="x" label="faster" color="#E1E900" />
```
