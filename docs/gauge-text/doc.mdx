## Examples

### Speed controls only the count-up

`speed` drives how fast the number counts up. The gauge icon itself is fixed — nothing about it moves; only the number and label change as it plays.

<DemoCanvas>
  <DemoPreview><SlowDemo /></DemoPreview>
  <DemoCode>
    ```tsx
    <GaugeText
      value={2.4}
      decimals={1}
      suffix="x"
      speed="slow"
      label="slower on cold starts"
      color="#F43F5E"
    />
    ```
  </DemoCode>
</DemoCanvas>

<DemoCanvas>

## Usage

```tsx
import { GaugeText } from "@/components/gauge-text";

<GaugeText value={89} suffix="x" label="faster" />
```
