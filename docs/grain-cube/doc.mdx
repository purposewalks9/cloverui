## Usage

A grainy, isometric 3D cube rendered on the GPU, with a flowing gradient on each face. Drag to spin it.

```tsx
import { GrainCube } from "@/components/grain-cube";

<div className="w-64">
  <GrainCube theme="green" />
</div>
```

It's a square canvas, so size it with a `w-*` class on a wrapping element (it fills the width at `aspect-square`).

Themes: `green`, `ember`, `ice`, `violet`, `mono`. For your own palette pass 2 to 8 colors:

```tsx
<GrainCube colors={["#52c4dc", "#f2f6ea", "#25e15f", "#0b5a2b"]} />
```

Each face leans toward a different part of the palette, so faces read as distinct even with one color list. It pauses when off-screen or in a hidden tab, and falls back to a static gradient diamond if WebGL is unavailable.
