## Usage

```tsx
import { BlockText } from "@/components/block-text";

<BlockText
  words={["Welcome", "Hello", "Thanks"]}
  colors={["#16a34a", "#ff5a1f", "#0029ff"]}
  className="text-6xl"
/>
```

The block works like a 3D cube that keeps rolling forward. The current word tips away over the top while the next one comes up from the bottom, and the loop goes on forever.

Each word gets the color at the same position in `colors`. If there are fewer colors than words, the colors repeat. The block is as wide as the longest word, so it never jumps in size.

Set the size with a text class in `className`. Everything else scales with it. When reduced motion is on, the words swap without the roll.
