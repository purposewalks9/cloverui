# Component audit — 2026-10-12

Baseline: `3ea542efa164494fb77481f9730de153eaa11d4d` on `main`, including the approved black-glass Switch. Scope: all 30 registry components, their installation entries, and the available UI-review skill. The original ignored `.claude/skills` packages were not present in the available repository; they were not silently reconstructed or claimed as recovered.

The component and demo designs were preserved. This pass fixes specific integration and lifecycle defects and packages reusable maintenance skills. It does not certify every design system, browser, accessibility state, or input combination as bug-free.

## Verification evidence

- **Registry:** build and checker passed for all 30 components. Fault injection confirmed that the checker rejects an undeclared icon dependency, missing client boundary, and stale generated source.
- **Types:** `pnpm registry:typecheck` passed. A separate consumer fixture type-checked all 30 generated components with declared packages, a minimal `cn`, and the declared Button dependency. Component imports were relocated to the consumer directory as an installer would do. This was not a network installation test against the deployed registry.
- **Lint:** all registry components and the registry checker passed with zero errors. Two existing AppleMusicCard `<img>` advisories remain; replacing them with Next Image would impose a framework-specific dependency on the portable component.
- **Interactions:** 13 browser checks covered empty-to-loaded chart data, consumer refs and cleanup on four components, form button behavior, GaugeText updates/invalid numbers, DropText play/reset ordering, CSS-token Spinner colors, and mocked AppleMusicCard requests/errors/albums. No page exceptions occurred.
- **Rendering:** compared nine components together: SoftButton, Switch, GaugeText, Spinner, RichText, GridReveal, CandleChartStick, one since-removed component, plus SignPad's idle trigger. The gallery used explicit still/settled states. Light, dark, and custom palettes at 760px and 360px produced six before/after image pairs with zero differing pixels. This is nine rendered components, not full visual coverage of all 30 or every animation phase.
- **Source design checks:** all 30 components retained matching JSX class/style, SVG geometry/paint, and motion attribute expressions. This guards direct visual edits; it does not prove that an internal behavior change can never affect rendering.
- **Performance:** in one Chromium sample after settling, paused Spinner went from 25 scheduled frames in 400ms to 0. At speed zero, GrainCube went from 23 draws to 0 and ThermalFlow from 25 draws to 0. These are eliminated idle operations in a fixture, not general FPS or page-load benchmarks. RGB shader uniforms changed from all-zero output to the expected red/blue values for numeric RGB inputs.
- **Skills:** all three packages passed the skill validator. Fresh-context trials kept the glass artwork intact during review and committed only intended metadata in an isolated repository, leaving an unrelated draft uncommitted and publishing nothing.
- **Full application:** `pnpm exec tsc --noEmit` still reports the two baseline icon-import errors below. A successful full production build is not claimed. Microphone permissions, real external music services, every GPU, 200% zoom, all keyboard flows, and every animation state were not certified.

## Remaining findings

1. **Full-site type-check blocker:** `components/stem/toc.tsx` imported `SiOpenai`, which the installed `@icons-pack/react-simple-icons` does not export. The error also occurred in the baseline. Restore the intended matching logo asset or an approved compatible export, then rerun the full check. A different brand mark was not substituted merely to clear the build.
2. **SignPad integration:** automatic ink selection watches `.dark` only on `document.documentElement`. Nested/data-attribute themes can use the wrong ink. Its signing panel also handles Escape and undo/finish shortcuts on `window` without restricting the active instance. Source reproduction: open two pads or focus another input while a pad is open. A scoped keyboard owner and an optional ink override would address this without repainting the defaults; these paths were not changed in this pass.
3. **Reduced motion is incomplete:** GaugeText, GridReveal, DropText, Spinner, PulseLoader, TokenFall, and RichProgress do not independently adapt all animations to the OS preference. GrainCube, ThermalFlow, and NucleusText sample that preference when their effects start rather than subscribing to later changes. TextGif's underlying GIF needs a still asset for a no-motion presentation. This remains an accessibility follow-up; the audit does not claim complete reduced-motion compliance.
4. **Theme colors are not universally interchangeable:** shader parsers accept restricted literal formats, canvas particles do not resolve arbitrary CSS variables, and several components intentionally contain material colors. See `component-integration.md` for the exact mapping and override contract. Contrast across arbitrary custom palettes still needs measurement in the host app.
5. **Additional performance opportunities:** LogoPop keeps its post-entry bounce interval while offscreen, TokenFall continues its physics/render loops while mounted, and LiquidButton can continue scheduling frames while the document is hidden even though drawing is skipped. Cleanup and current behavior were inspected, but those lifecycles were not rewritten or benchmarked here. NucleusText's one-shot canvas sizing also warrants a resize/font-loading check before claiming responsive particle alignment.

These findings are recorded so future work can target real gaps while preserving the approved designs.
