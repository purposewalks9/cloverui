## Examples

### Characters

<DemoCanvas>
  <DemoPreview><CharacterDemo /></DemoPreview>
  <DemoCode>
```tsx
    <DropText splitBy="characters" stagger={0.025}>
      Every letter falls.
    </DropText>
```
  </DemoCode>
</DemoCanvas>

### Faster speed

`speed` scales how fast each unit falls and how tightly staggered they are — it never changes when the drop starts.

<DemoCanvas>
  <DemoPreview><FastDemo /></DemoPreview>
  <DemoCode>
```tsx
    <DropText speed={2.5}>
      Quick drop, no delay.
    </DropText>
```
  </DemoCode>
</DemoCanvas>

### No bounce

Set `bounce` to `0` for a plain, weightless fall instead of a settling overshoot.

<DemoCanvas>
  <DemoPreview><NoBounceDemo /></DemoPreview>
  <DemoCode>
```tsx
    <DropText bounce={0} speed={1.5}>
      A crisp, weightless fall.
    </DropText>
```
  </DemoCode>
</DemoCanvas>

## Ref API

`DropText` exposes `play()` and `reset()` through a ref when you need to trigger the drop yourself.
