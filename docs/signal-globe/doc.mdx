## Usage

```tsx
import { SignalGlobe } from "@/components/signal-globe";

<SignalGlobe
  server={{
    id: "sin-1",
    label: "Singapore",
    region: "ap-southeast-1",
    lat: 1.3521,
    lng: 103.8198,
  }}
  requests={[
    {
      id: "request-42",
      origin: { lat: 35.6762, lng: 139.6503, label: "Tokyo" },
      startedAt: Date.now(),
      status: "pending",
    },
  ]}
/>
```

Signal Globe is a true WebGL globe: request origins and server locations use latitude and longitude, and each request follows an elevated arc to the selected server. It has no map API key or tiles to configure.

Pass the latest rolling slice from your telemetry stream as `requests`. A request can provide its own `destination`; otherwise it routes to `server`. Use a stable `id` for each request. When `startedAt` is supplied, the request automatically leaves the visualization after its duration and retention period; omit it for a persistent connection.
