## Usage

```tsx
import { AppleMusicCard } from "@/components/apple-music-card";

<AppleMusicCard url="https://music.apple.com/us/album/drift-away/1234567890?i=1234567899" />
```

Pass a song or album link from music.apple.com. The title, artist and artwork load from the public iTunes API, so no API key is needed.
