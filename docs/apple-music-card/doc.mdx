## Usage

```tsx
import { AppleMusicCard } from "@/components/apple-music-card";

<AppleMusicCard
  urls={[
    "https://music.apple.com/us/song/blinding-lights/1499378607",
    "https://music.apple.com/us/song/levitating/1538003843",
    "https://music.apple.com/us/song/as-it-was/1615585008",
  ]}
/>
```

Pass song or album links from music.apple.com. The title, artist and artwork load from the public iTunes API, so no API key is needed. With more than one link, numbered tabs appear at the bottom of the card. Click a number, or use the arrow keys, to switch songs in the same card. For a single song, pass `url` instead.

To change songs from outside, for example on a timer, control the card with `index` and `onIndexChange`:

```tsx
const [index, setIndex] = React.useState(0);

<AppleMusicCard urls={urls} index={index} onIndexChange={setIndex} />
```
