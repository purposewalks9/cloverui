## Usage

```tsx
import { EffortSlider } from "@/components/effort-slider";

<EffortSlider />
```

A slider for choosing how hard an AI model should think. It has four levels by default: Low, Medium, High and Max. The knob is a brain icon.

The fill and the brain change color as the level goes up, and small sparkles flow toward the brain. Higher levels move faster. The lowest level has no fill and a gray brain. The highest level glows.

Pick colors with `theme`:

- `"aurora"`: indigo, violet and pink (default)
- `"ocean"`: blues and teal
- `"ember"`: amber, orange and red
- `"forest"`: greens and lime
- `"mono"`: grays

Each theme works in light and dark mode.

```tsx
<EffortSlider theme="ocean" />
```

Click the track or drag the brain. When you let go, it snaps to the nearest level.

Pass `levels` to use your own names. Pass `value` and `onValueChange` to control it. The value is the index of the level, starting at 0:

```tsx
const [effort, setEffort] = React.useState(2);

<EffortSlider
  levels={["Fast", "Balanced", "Thorough", "Deep"]}
  value={effort}
  onValueChange={(index, level) => setEffort(index)}
/>
```

Each level has a small tag in the corner: Fastest, Faster, Smarter and Smartest by default. Pass `tags` to use your own words. Set `recommended` to a level's index to tag that level "Recommended".

It uses your theme's card and text colors, so it fits light and dark mode.

Keyboard: the arrow keys move one level, and Home and End jump to the ends. Screen readers read the level name. With reduced motion on, nothing slides or sparkles.
