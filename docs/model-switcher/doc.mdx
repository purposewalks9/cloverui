## Usage

```tsx
import { ModelSwitcher } from "@/components/model-switcher";

<ModelSwitcher />
```

A small menu for your chat input. It picks which AI model to use and how hard it thinks. Closed, it's a pill that shows the model and level, like "Opus 5.5 Medium".

Click it to open a menu with two rows:

- **Model:** a list of models with their logos. The picked one shows a small animated orb.
- **Effort:** an [Effort Slider](/docs/effort-slider) you can click or drag.

The pill updates when you leave a submenu, so it doesn't flicker while you choose. If there isn't room on the right, submenus open on the left.

### Syncing with Effort Slider

Give it and an Effort Slider the same state, and they stay in sync:

```tsx
import { EffortSlider } from "@/components/effort-slider";

const [effort, setEffort] = React.useState(1);

<ModelSwitcher effort={effort} onEffortChange={setEffort} />
<EffortSlider value={effort} onValueChange={setEffort} />
```

Use the same `effortLevels` and `effortTheme` on both so they match.

### Models and logos

It comes with Opus 5.5, Grok 4.7, GPT-6, Astra and Muse Spark. Black and white logos follow your text color.

Pass your own list to change them. Use `ModelLogo` for the built-in logos (`openai`, `claude`, `grok` and `meta`), or pass any icon:

```tsx
import { ModelLogo, ModelSwitcher } from "@/components/model-switcher";

<ModelSwitcher
  models={[
    { value: "gpt-6", label: "GPT-6", icon: <ModelLogo name="openai" /> },
    { value: "opus-5.5", label: "Opus 5.5", icon: <ModelLogo name="claude" /> },
    { value: "my-model", label: "My Model", icon: <MyIcon /> },
  ]}
  effortLevels={["Quick", "Balanced", "Deep"]}
  onModelChange={(model) => console.log(model)}
/>
```

The menu opens below the pill. Pass `side="top"` to open it above.

Keyboard: arrow keys move around, Enter or Right opens a submenu, and Left or Escape goes back. Clicking outside closes it.
