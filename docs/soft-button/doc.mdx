## Usage

```tsx
import { SoftButton } from "@/components/soft-button";

<SoftButton color="green">Get started</SoftButton>
```

The component deliberately does not expose `className`. Its gradients, text treatment, radius, glow, and interaction states remain part of the Clover UI design system.
