## Usage

```tsx
import { SoftButton } from "@/components/soft-button";

<SoftButton color="green">Get started</SoftButton>
```

Use `asChild` to give a link the button styles.

```tsx
<SoftButton asChild color="yellow">
  <a href="/sponsor">Sponsor</a>
</SoftButton>
```

It also accepts every native button prop, like `disabled` and `onClick`.
