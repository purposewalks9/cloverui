## Usage

```tsx
import { PinDrop } from "@/components/pin-drop";

export function Office() {
  return <PinDrop place="London" />;
}
```

Pin Drop is a real, detailed world map with roads, cities, rivers and parks. Give it a place and it flies there and drops a red pin on the exact spot, with the place name under it. The pin bounces as it lands and sends out a soft pulse so it's easy to spot. People can drag the map and zoom with pinch, Ctrl + scroll or the keyboard, and the pin stays on its spot.

The map is drawn with [MapLibre](https://maplibre.org) using free [OpenFreeMap](https://openfreemap.org) tiles built from [OpenStreetMap](https://www.openstreetmap.org) data. No API key or account is needed. It follows your site's light and dark mode, and it fills the width of its container.

### Showing a place

Pass `place` with any city, state, country or address, in any language: "London", "Awka", "Texas", "Japan". The map looks it up a moment after typing stops, then flies there. Cities and countries are framed so the whole area fits, and `zoom` sets how close it can get.

By default, names are looked up with [Photon](https://photon.komoot.io), a free OpenStreetMap search with no API key. Only the `place` text is sent to it, never the device's location. To use a different service, such as Google or Mapbox, pass a `geocoder` function that takes the text and returns `{ name, lat, lng }`, or `null` when nothing matches.

If you already have coordinates, pass `location` with a latitude and longitude, and `label` for the name:

```tsx
<PinDrop location={{ lat: 6.2104, lng: 7.0741 }} label="Awka" />
```

### Finding the visitor's location

The round button in the top corner finds where the visitor is right now. The browser asks for permission, the map flies to their position and drops the pin there with their city name. Pressing it again flies back to them. Hide the button with `locateButton={false}`.

To start locating from your own button instead, set `locate`. The browser only asks when `locate` becomes `true`, so turn it on after the person asks, never on page load:

```tsx
"use client";

import { useState } from "react";
import { PinDrop } from "@/components/pin-drop";

export function MyLocation() {
  const [locate, setLocate] = useState(false);

  return (
    <>
      <PinDrop place="London" locate={locate} locateButton={false} />
      <button onClick={() => setLocate(true)}>Use my location</button>
    </>
  );
}
```

If the person blocks access, or the device can't find a position, a short message shows in the corner and the map stays where it was.

### How accurate it is

The browser picks the best location source it has:

- **Phones with GPS:** usually within 5 to 20 meters outdoors.
- **Laptops and desktops:** estimated from nearby Wi-Fi networks, usually within 20 to 100 meters.
- **No GPS or Wi-Fi data:** estimated from the internet connection. This is often only accurate to the city, and VPNs can place someone in the wrong country.

Each reading includes `accuracy` in meters, passed to `onLocationChange`.

### Privacy

The map never asks for location by itself or on the server, and it never stores or logs coordinates.

To show the city name under the pin, it looks up a rounded position (about 1 km precise) with [BigDataCloud](https://www.bigdatacloud.com/free-api/free-reverse-geocode-to-city-api)'s free city lookup. The exact position never leaves the browser, apart from loading the map tiles around it. Pass `reverseGeocoder={null}` to turn the lookup off, and use `label` to name the pin yourself.

### States

Use `onStatusChange` to react to what's happening:

- `idle`: not locating.
- `locating`: waiting for the browser.
- `located`: the visitor's position is showing.
- `denied`: the person blocked location access.
- `unavailable`: the device couldn't find a position.
- `timeout`: finding a position took too long.
- `unsupported`: the browser has no geolocation.

### Map style

`theme` picks the light or dark map. `auto` follows your site's `dark` class, or the system setting when there isn't one. To use other map designs, pass any MapLibre style URL to `mapStyle`, for one theme or both:

```tsx
<PinDrop
  place="Tokyo"
  mapStyle={{ light: "https://tiles.openfreemap.org/styles/bright" }}
/>
```

The defaults are exported as `pinDropMapStyles`. Use `marker` to recolor the pin, for example `marker={{ color: "#2563eb" }}`.
