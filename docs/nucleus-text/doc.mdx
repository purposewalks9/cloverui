## Usage

```tsx
import { NucleusText } from "@/components/nucleus-text";

<NucleusText className="text-6xl font-semibold">
  generates
</NucleusText>
```

`NucleusText` keeps your text fully rendered in its chosen color. On page load, the text makes one quick shake while small particles rush inward from different angles, fade as they reach the text, and disappear. The effect plays once; it never assembles or recolors the letters.
