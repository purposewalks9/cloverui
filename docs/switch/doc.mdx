## Examples

### Controlled

Hold the state yourself with `checked` and `onCheckedChange`. Leave both out and use `defaultChecked` to let the switch keep its own state.

<DemoCanvas>
<DemoPreview center className="min-h-64 md:min-h-72">
<SwitchControlledExample />
</DemoPreview>
<DemoCode>
```tsx
const [enabled, setEnabled] = React.useState(true);

<Switch aria-label="Wi-Fi" checked={enabled} onCheckedChange={setEnabled} />
```
</DemoCode>
</DemoCanvas>

### Color

`color` takes any CSS color for the track when it's on. The frame and knob stay black in light and dark mode.

<DemoCanvas>
<DemoPreview center className="min-h-64 md:min-h-72">
<SwitchColorExample />
</DemoPreview>
<DemoCode>
```tsx
<Switch aria-label="Blue" color="#0b87da" />
<Switch aria-label="Purple" color="#7c3aed" />
<Switch aria-label="Orange" color="#f97316" />
```
</DemoCode>
</DemoCanvas>

### Without labels

`showLabels={false}` hides the fixed **ON** and **OFF** labels. Keep the `aria-label` so screen readers still know what it controls.

<DemoPreview center className="min-h-64 md:min-h-72">

```tsx

```
</DemoCode>
</DemoCanvas>

## Usage

```tsx
import { Switch } from "@/components/switch";

<Switch aria-label="Notifications" />
```

Tab to it and press Space or Enter to flip it. Always give it an `aria-label`.
