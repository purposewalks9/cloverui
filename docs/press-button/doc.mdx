## Usage

```tsx
import { PressButton } from "@/components/press-button";

<PressButton onClick={() => console.log("Run")}>Run</PressButton>
```

A soft, rounded press button in one solid color, with a thin rim at the top and bottom, wider curved sides, a lightly shaded face with a softly stretched oval edge, and a soft shadow underneath. Pressing lowers the whole top into the base, using the same lift depth as Theme Toggle. The press is immediate; release gently returns the top to its resting height. The neutral material follows your site’s light or dark theme. Pick a color and the whole button turns that color, with white text, in both light and dark mode.

Mouse, touch, Enter and Space activate the native button. It defaults to `type="button"`; pass `type="submit"` to submit a form. Disabled buttons cannot activate. Reduced motion removes the return transition while preserving immediate pressed feedback. Standard button attributes, event handlers, `ref`, `className` and `style` reach the root button.

The component uses React 19, Tailwind CSS v4, the usual shadcn `cn` helper, and your host’s `ring` and `background` tokens for keyboard focus. It follows your site's light and dark mode through the `dark` class. `color` accepts a CSS color and is mixed into the rim, face and base.

```tsx
<PressButton color="#8b5cf6">Run</PressButton>
```
