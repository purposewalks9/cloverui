## Usage

```tsx
import { PressButton } from "@/components/press-button";

<PressButton onClick={() => console.log("Run")}>Run</PressButton>
```

A rounded press button with a softly curved bevel, a smooth concave face and a visible base. Pressing lowers the whole top into the base, using the same lift depth as Theme Toggle. The press is immediate; release gently returns the top to its resting height. The neutral material follows your site’s light or dark theme. Choose a custom color to tint the whole surface.

Use the circle shape for a round icon button. Give icon-only buttons an accessible name:

```tsx
import { Play } from "lucide-react";

<PressButton shape="circle" aria-label="Run">
  <Play aria-hidden fill="currentColor" />
</PressButton>
```

Mouse, touch, Enter and Space activate the native button. It defaults to `type="button"`; pass `type="submit"` to submit a form. Disabled buttons cannot activate. Reduced motion removes the return transition while preserving immediate pressed feedback. Standard button attributes, event handlers, `ref`, `className` and `style` reach the root button.

The component uses React 19, Tailwind CSS v4, the usual shadcn `cn` helper, and your host’s `ring` and `background` tokens for keyboard focus. Auto theme follows a `.dark` ancestor; use `theme="light"` or `theme="dark"` with other theme systems. `color` accepts a CSS color and is mixed into the rim, face and base. Circle buttons are for icons; use the pill shape for text labels.

```tsx
<PressButton color="#8b5cf6" theme="auto">Run</PressButton>
```
