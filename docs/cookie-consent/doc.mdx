## Usage

```tsx
import { CookieConsent } from "@/components/cookie-consent";

<CookieConsent
  onConsent={(preferences) => {
    if (preferences.analytics) loadAnalytics();
  }}
/>
```

A cookie banner for any site. Put it once in your root layout. A moment after the page loads it slides up into the bottom right corner. Its heading has a rich gradient and the key words in the message are highlighted. The buttons are your own shadcn `Button`, so they match the rest of your site.

**Accept all** turns every category on. **Reject all** keeps only the strictly necessary cookies. **Manage** opens a list of categories with a black GlossySwitch for each, and **Save choices** keeps exactly what was picked. Strictly necessary cookies are always on and can't be switched off. The registry installs GlossySwitch alongside the banner; manual installs need that component too.

The choice is saved in `localStorage` under `storageKey`, so the banner doesn't come back on the next visit. Read it anywhere with `getCookieConsent()` before loading a script:

```tsx
import { getCookieConsent } from "@/components/cookie-consent";

const consent = getCookieConsent();
if (consent?.preferences.analytics) loadAnalytics();
```

To let people change their mind later, for example from a "Cookie settings" link in your footer, control it with `open` and `onOpenChange`. It opens with their saved choices already switched on:

```tsx
const [open, setOpen] = React.useState(false);

<button onClick={() => setOpen(true)}>Cookie settings</button>
<CookieConsent open={open} onOpenChange={setOpen} />
```

Pass your own `categories` to change the list. Mark a category `required` to keep it always on, or `defaultEnabled` to switch it on when Manage opens:

```tsx
<CookieConsent
  categories={[
    { id: "necessary", label: "Strictly necessary", required: true },
    { id: "analytics", label: "Analytics", description: "Anonymous visit counts." },
  ]}
/>
```

The card uses your theme colors (`bg-background`, `border-border`, `text-muted-foreground` and so on), so it matches any shadcn theme. The heading switches between a dark and a light gradient with the `dark` class, so it follows your light and dark mode. With reduced motion on, it fades in instead of sliding up.
