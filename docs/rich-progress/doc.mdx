Every "tuning" panel on this site — the one docked to the right of each
playground above — is built on top of this component. Its `onChange` and
draggable track are what make each numeric control (and every "Prism IOR"
/ "Rainbow glow" style slider you'll see across the docs) feel the way it
does, not a plain `<input type="range">`.

## Usage

```tsx
import { RichProgress } from "@/components/rich-progress";

<RichProgress value={65} color="red" />
```

### Interactive

```tsx
import { useState } from "react";
import { RichProgress } from "@/components/rich-progress";

export function Example() {
  const [value, setValue] = useState(65);

  return (
    <RichProgress
      value={value}
      onChange={setValue}
      color="red"
    />
  );
}
```

### Custom label

```tsx
<RichProgress
  value={3}
  valueLabel="3/10"
  color="emerald"
/>
```

### As a settings control

`RichProgress` only speaks 0–100, so to drive an arbitrary range (say,
Prism IOR from 1.0–3.0) map the value in and back out:

```tsx
const min = 1;
const max = 3;
const percent = ((ior - min) / (max - min)) * 100;

<RichProgress
  value={percent}
  onChange={(next) => setIor(min + (next / 100) * (max - min))}
  label="Prism IOR"
  valueLabel={ior.toFixed(2)}
  size="sm"
/>
```
