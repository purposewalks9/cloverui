## Usage

```tsx
import { RichProgress } from "@/components/rich-progress";

<RichProgress value={65} color="red" />
```

### Make it draggable

Pass `onChange` and it becomes a slider you can drag or move with the arrow keys.

```tsx
import { useState } from "react";
import { RichProgress } from "@/components/rich-progress";

export function Example() {
  const [value, setValue] = useState(65);

  return <RichProgress value={value} onChange={setValue} label="Volume" />;
}
```

### Custom value label

```tsx
<RichProgress value={30} valueLabel="3/10" color="emerald" />
```

### Other ranges

The value always goes from 0 to 100. To use another range, convert it in and out.

```tsx
const min = 1;
const max = 3;

<RichProgress
  value={((zoom - min) / (max - min)) * 100}
  onChange={(next) => setZoom(min + (next / 100) * (max - min))}
  label="Zoom"
  valueLabel={zoom.toFixed(2)}
/>
```
