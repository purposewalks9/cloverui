## Usage

```tsx
import { SignPad } from "@/components/sign-pad";

<SignPad
  onComplete={(signature) => {
    console.log(signature.svg);
  }}
/>
```

### Save the signature

`onComplete` receives a `SignPadValue` containing both ready-to-use exports and the original strokes.

```tsx
<SignPad
  onComplete={(signature) => {
    form.setValue("signature", signature.dataUrl);
  }}
/>
```

### Restore an existing signature

Pass the previous value to `defaultValue` when the signature should open in its completed state.

```tsx
<SignPad defaultValue={savedSignature} />
```

### Customize the ink

```tsx
<SignPad
  ink="#7c3aed"
  strokeWidth={3.5}
  minInk={0.24}
/>
```

### Custom labels

The labels object is useful for product-specific copy or localization.

```tsx
<SignPad
  labels={{
    start: "Add signature",
    finish: "Save signature",
    done: "Signature saved",
    title: "Approval",
  }}
/>
```

## Behavior

- Draws with mouse, touch, or a pressure-sensitive pen.
- Uses coalesced pointer events when available for smoother strokes.
- Adjusts stroke width from pointer speed and pen pressure.
- Supports undo, clear, edit, and cancel actions.
- `Ctrl/Cmd + Z` undoes, `Ctrl/Cmd + Enter` finishes, and `Escape` cancels.
- Emits a cropped transparent PNG, cropped SVG, dimensions, and raw strokes.
- Uses `ResizeObserver` and device-pixel-ratio scaling so the canvas stays sharp.
- Uses `prefers-reduced-motion` to disable decorative transitions.

## SignPadValue

```tsx
interface SignPadValue {
  dataUrl: string;
  svg: string;
  width: number;
  height: number;
  strokes: SignStroke[];
}
```

The PNG is transparent and tightly cropped to the ink. The SVG is useful when the signature needs to remain scalable, while `strokes` lets you restore or process the original drawing data.
