## Usage

```tsx
import { SignPad } from "@/components/sign-pad";

<SignPad />
```

### Interactive

```tsx
import { useState } from "react";
import { SignPad, type SignPadValue } from "@/components/sign-pad";

export function Example() {
  const [signature, setSignature] = useState<SignPadValue | null>(null);

  return (
    <SignPad
      onChange={setSignature}
    />
  );
}
```

### Customize the stroke

The ink automatically follows the current theme. It uses dark ink in light mode and light ink in dark mode.

```tsx
<SignPad
  strokeWidth={3.5}
  minInk={0.24}
/>
```

### Existing signature

You can provide an existing completed signature through `defaultValue`.

```tsx
<SignPad
  defaultValue={signature}
/>
```

## Behavior

* Ink automatically follows the current `.dark` theme.
* Light mode uses dark ink.
* Dark mode uses light ink.
* The stroke width can be adjusted with `strokeWidth`.
* `minInk` controls the minimum amount of drawing required to finish.
* `accent` controls the finish action accent color.
* `onChange` receives the current saved signature.
* `onComplete` fires when a valid signature is finished.
* `onCancel` fires when signing is closed without finishing.
