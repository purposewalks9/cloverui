## Usage

```tsx
import { SignPad } from "@/components/sign-pad";

<SignPad />
```

### Save the signature

```tsx
import { useState } from "react";
import { SignPad, type SignPadValue } from "@/components/sign-pad";

export function Example() {
  const [signature, setSignature] = useState<SignPadValue | null>(null);

  return <SignPad onChange={setSignature} />;
}
```

The value includes the signature as an image, an SVG and the raw strokes.

### Start with a signature

```tsx
<SignPad defaultValue={signature} />
```

The ink is dark in light mode and light in dark mode.
