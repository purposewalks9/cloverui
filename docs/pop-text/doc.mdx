## Usage

```tsx
import { PopText } from "@/components/pop-text";

<PopText className="text-6xl">
  so poppy
</PopText>
```

`PopText` renders each letter (or word) as a chunky, outlined bubble in the site's `font-pop` display face, popping into place with a springy bounce. Hover a letter to give it an extra squish.
