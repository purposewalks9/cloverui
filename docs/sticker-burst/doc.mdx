## Usage

```tsx
import { StickerBurst } from "@/components/sticker-burst";

<StickerBurst
  title="Launch week"
  stickers={["New drop", "Day 1", "Open source", "Ship it", "Free forever"]}
  className="h-96"
/>
```

A small title label sits in the middle. It grows, then dozens of stickers pop in around it and pile on top of each other until they fill the space. While the pile is full, stickers keep jumping to the front. Then everything shrinks back into the single label, and it starts again.

With `trigger="hover"`, it stays small until the pointer moves over it and shrinks back when the pointer leaves.

Stickers reuse the `stickers` text in order and repeat it to reach `count`. Their places and sizes are random but stay the same on every load. Each sticker fades between two neighbouring colors from `colors`, and the title uses the first color.

It fills its own box, which is `h-80 w-full` by default. Change it with `className`. Text size classes scale every sticker. With reduced motion on, the full pile shows without moving.
