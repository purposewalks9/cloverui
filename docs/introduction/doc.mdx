Clover UI is a collection of modern React components for thoughtful interfaces, built with Motion and Tailwind CSS. Each one installs as source code with the shadcn CLI, so the file lands in your project and is yours to change. It's free and [open source](https://github.com/purposewalks9/cloverui).

Most interfaces feel still. The button works, but it doesn't answer you. The page loads, but nothing arrives. I started Clover UI because I wanted components that feel alive when you touch them: a press that gives a little back, a number that rolls into place, a cursor that seems to know you're there.

**Motion has a job.** Every animation here tells you something: your click landed, something changed, the app is still thinking. If a movement doesn't say anything, it doesn't ship.

**Feeling lives in the small things.** Spring timing, a soft shadow, the way a label settles after it moves. Nobody notices them one by one, but everyone notices when they're gone.

**It should be yours.** Every component is a single file with only the dependencies it needs. Copy it, rename it, take it apart. Nothing is locked inside a package.

**It should be kind.** Components follow your light or dark theme, work from the keyboard, and calm down when someone has asked for reduced motion.

## Getting started

Try every option in the live playground on a component's page, then copy the code. To set things up, [install Clover UI](/docs/installation), use it from your AI editor with [MCP](/docs/mcp), or browse the components in the sidebar.
