Clover UI is a collection of animated React components built with Tailwind CSS and Motion. Each one installs as source code with the shadcn CLI, so the file lands in your project and is yours to change.

Every component is a single file with only the dependencies it needs. You can try every option in the live playground on its page, then copy the code. Components follow your light or dark theme and respect `prefers-reduced-motion`.

To get started, [install Clover UI](/docs/installation), use it from your AI editor with [MCP](/docs/mcp), or browse the components in the sidebar.
