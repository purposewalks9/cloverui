Clover UI is a collection of animated React components built with Tailwind CSS and Motion. Each one installs as source code with the shadcn CLI, so the file lands in your project and is yours to change.

- **Source you own.** One file per component, with only the dependencies it needs.
- **A live playground.** Try every option on the component's page, then copy the code.
- **Light, dark and reduced motion.** Components follow your theme and respect `prefers-reduced-motion`.

[Install Clover UI](/docs/installation), use it from your AI editor with [MCP](/docs/mcp), or browse the components in the sidebar.
